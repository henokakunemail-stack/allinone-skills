# allinone-skills

Agent Skills (open standard, https://agentskills.io) for AI coding agents — Claude Code, Claude app, OpenAI Codex, Google Antigravity, Cursor, and any agent that reads the `SKILL.md` format.

## Skills

- [`idea-to-done/`](idea-to-done/) — v1.1. Turns a raw idea into a clarified foundation (PRD), a traceable plan, real execution and deep independent verification, run like a small office of roles (Product Manager, Tech Lead, Engineering Manager, Engineer, QA Engineer, plus activated specialists). See `idea-to-done/README.md` for install paths per agent and `idea-to-done/SKILL.md` for the full workflow.
